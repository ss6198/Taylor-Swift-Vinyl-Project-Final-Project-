2. Describe the size and structure of your data
I created two different data sets. I realized while going to the stores that a lot of record stores do not have more recent music from the last 20 years. I made one dataset based on whether the stores I visited had any Taylor Swift Vinyls, and a second dataset that includes the specific album and price of the Taylor Swift vinyls in the stores that I was able to find the vinyls. 
Number of rows
First Data Set: 12 rows
Second Data Set: 16 rows
Number of columns
First Data Set : 2
Second Data Set: 4
What each row represents
Data Set 1: Each row in the dataset represents a different store or store location I visited to investigate the availability of Taylor Swift vinyl records. For each store, I recorded its name and whether Taylor Swift vinyls were available, using a Yes or No response. There are 12 rows in total, representing the 12 store locations I visited.
Data Set 2: My second dataset contains 16 rows and 4 columns. Each row represents a specific Taylor Swift vinyl album found at one of the stores I visited, including its quantity and price.
What each important column represents
Dataset 1: The first column represents the name of each store I visited, while the second column indicates whether Taylor Swift vinyl records were available at that location using a Yes or No response.
Dataset 2: The first column represents the name of the store where the vinyl was found. The second column identifies the specific Taylor Swift album available. The third column records the number of copies of that album in stock, and the fourth column represents the price of one copy in US dollars.

Data types of important variables
Dataset 1: The store name is a categorical variable because it identifies different store locations. Vinyl availability is a binary categorical variable because it is only yes or no.
Dataset 2: Store names and album titles are also categorical variables because they identify different stores and albums. Quantity is a numerical variable because it represents the number of vinyl copies available. Price is a numerical variable measured in dollars
Coverage: time period, geography
